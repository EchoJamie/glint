流光 Glint 0.1.0

打开「安装流光.app」并点击安装。它会校验载荷签名，安装到
~/Library/Input Methods/Glint.app。替换失败时恢复旧程序，成功后删除暂存的旧程序。
个人词库、设置及已下载的方案不会被替换。

安装前请先完成正在输入的文字。更新时，安装器会暂时切换为英文，
自动退出旧版流光后再替换程序。

第一次安装后，点击「打开键盘设置」，在「文本输入」中点「编辑…」，
然后添加「流光」。已经添加过的用户，完成后从菜单栏选择「流光」即可。
如果旧版暂时无法退出，安装器会停止更新并提示重试。

「Glint-0.1.0-source.tar.gz」提供本次发布对应的源码、许可证与构建脚本。

输入法、安装器及 DMG 均使用约定的 Apple Development 证书签名。
本版依约暂不进行 Developer ID 认证与 Apple 公证。
