# 输入与候选行为

本文是当前产品行为约定，供界面和按键修改时核对；历史试验步骤不属于产品规则。

## 组合与键盘

- Glint 默认中文；英文可使用系统 ABC。Caps Lock 位置的中/英键短按切源、长按大写由 macOS 设置处理，Glint 不在 `flagsChanged` 中再实现一套计时器。
- 拼音内部先由 Rime 移动光标。光标未到末尾时，左右键不能被候选面板抢走；末尾右键可向右移动高亮，候选首列左键交还拼音光标。预编辑插入点从 Rime 的 UTF-8 偏移转换为 AppKit 的 UTF-16 位置。
- 有候选时，数字键选当前可见编号；空格确认当前高亮；上下、左右、翻页和滚动移动屏幕候选。向下可展开，回到首行时收起；Escape 在展开态先收起，其余取消行为交给 Rime。
- 上屏、取消、切源和离开客户端应清除旧候选及触摸状态。已确认提交只能消费一次；剩余未确认编码在切源时按原始拼音交还宿主。

## 屏幕与 Touch Bar

屏幕使用不抢焦点的 AppKit 面板，紧凑行按内容宽度收窄，展开时按实际可用区域排布。设置预览复用同一绘制。Touch Bar 显示当前屏幕操作行的候选，两端的高亮和确认回到同一 Rime 索引；鼠标单击只改高亮，双击确认。实体 Touch Bar 轻点确认一次。

Touch Bar 回调若无法唯一匹配当前可见候选，或者属于旧组合代次，就拒绝确认。上屏后的下一词联想只显示在 Touch Bar，允许连续手动轻点；任何键盘输入都先撤回联想，再交给普通输入路径，空格、数字、方向键不作为联想快捷键。没有 Touch Bar 时联想不可用，屏幕候选和普通中文输入照常工作。

Touch Bar 使用系统宿主的内部属性通道，不属于公开 SDK 的稳定承诺。新 macOS 版本需重新核对中文显示、高亮、确认、撤回和切源残留；已知边界见[排障与踩坑](troubleshooting.md)。
